# docs

The published documentation site, built by MkDocs from `mkdocs.yml` at the repo
root. This README is excluded from the site (`exclude_docs` in `mkdocs.yml`).
CI component: **docs**.

```
docs/
├── index.md             the animated landing page (site root, not in the sidebar)
├── home.md              the documentation entry page
├── getting-started.md   install and first run
├── features-*.md        one page per feature
├── configure-*.md       configuration guides
├── agents-*.md          per-agent notes (Claude Code, Codex, OpenCode)
├── develop-*.md         architecture, principles, public API, contributing
├── troubleshooting.md, issue-ops.md
├── img/                 committed images; screenshots are regenerated by CI
├── examples/            copyable example configs
├── javascripts/ stylesheets/ logos/   site assets
├── hooks/               MkDocs build hooks
└── design-system.md     the TUI's visual contract (not published)

grove.schema.json is generated at build time (`make docs-schema`) and gitignored.
```

```bash
make docs          # serve locally with live reload
make docs-build    # strict build, as CI runs it
```

**Screenshots are regenerated on every push to `main`** by
`.github/workflows/screenshots.yml`, which then republishes the site. Hand-edit
`img/screenshots/` only for images no capture produces. Page structure and the
house style are in [CLAUDE.md](CLAUDE.md).
