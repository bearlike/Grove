# tests/restart — restart survival

> ↑ [tests](../CLAUDE.md) · [root](../../CLAUDE.md)

Every row here is *do X → SIGKILL the daemon → start it → assert the invariant*, against a real `grove daemon serve` child (`daemon_child`, `kill9_and_restart`). A daemon restart is routine (every reinstall and config change), so "correct between restarts" is not correct.

- **The child is isolated by ENV and CONFIG only.** It loads no conftest, so its `XDG_STATE_HOME`/`XDG_CONFIG_HOME`/`TMUX_TMPDIR`/`HOME` are private and `container.enabled=false` is pinned in the config it reads; every inherited `GROVE_*`/`TMUX*` variable is dropped. Teardown signals only a pid the fixture spawned. See the `test_client_http.py` / `test_local_transport.py` lessons in [tests](../CLAUDE.md) for what leaked before.
- **Seed durable state the way another Grove process would**: write the store, watch log or auth file from the pytest process (`daemon.store()`, `daemon.auth()`), then let the child read it. The bearer is minted here and validated there, which is exactly the cross-process contract under test.
- **A watch's recipient must be an existing workspace record, or the start-up reconcile cancels it.** `StandingWatches.reconcile` cancels every pending watch addressed to a workspace whose record is GONE; a paused one keeps the agent's own waits (timer/ci/command) and loses only its standing ticket/trigger/supervise rows. A row seeded against an absent workspace therefore reads `cancelled` after the restart and looks like lost durability when it is the reconcile doing its job.
- **A recovered watch is re-armed with jitter across its own interval**, so "fires after restart" is asserted by polling up to one interval past the start, never immediately.
- **A row the engine does not satisfy today is `xfail(strict=True)` with the reason**, so the fix turns it red-for-XPASS and forces the marker off. Current gap: a steer after a SIGKILL with a native turn in flight is acknowledged and never reaches the provider (#1019).
- **The native rows need a FIXED port, because the worker reads the daemon's URL once at launch.** `native_daemon_child` pins `daemon.mailbox_url` to a port the child re-binds on every start, and a fixed `--print-port` announces BEFORE bind, so `start()` retries the first `/whoami` on a refused connection. The provider is `tests/native_fake.py`, shared with the native integration suite so the two cannot drift on what a provider says; `slow:<s>` is how a row keeps a turn in flight across the kill.
- **`/mailboxes/contacts` `live` is NOT owner presence**: a native workspace whose owner is gone still answers live because a message revives it. The honest re-registration signal is a steer flipping from 409 to 204, and the honest delivery signal is the provider's own log; a 204 alone is a receipt, never evidence the bytes arrived.
